# Export Survey to PDF (SurveyJS for Angular)

This example is used in the following help topic: [Export Survey to PDF in an Angular Application](https://surveyjs.io/Documentation/Pdf-Export?id=get-started-angular). It uses Angular 22.2.1 and Angular CLI 22.2.2.

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

## Requirements

Use Node.js 22.22.3 or newer in the 22.x line, 24.15.0 or newer in the 24.x line, or 26.x or newer. Run `npm ci` to install the locked dependencies.
