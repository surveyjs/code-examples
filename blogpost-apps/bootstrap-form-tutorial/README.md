# Bootstrap Forms vs. Form Engines

A side-by-side comparison of employee forms built with native JavaScript and SurveyJS Form Library, both styled with Bootstrap.

Read the [accompanying blog post](https://surveyjs.io/stay-updated/blog/bootstrap-forms-vs-form-engines).

## Run locally

Requires Node.js 20.19+ or 22.12+ and npm.

```sh
npm ci
npm run dev
```

Open the local URL printed in the terminal.

Run tests with `npm test` or create a production build with `npm run build`.
