# SurveyJS Creator v3 × Quasar

Get-started demo of SurveyJS Creator v3 inside a Vue 3 + [Quasar](https://quasar.dev/) SPA.

## Stack

- Vue 3
- Quasar 2
- `survey-creator-vue` / `survey-creator-core` / `survey-core` / `survey-vue3-ui` `3.0.0-beta.8`

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5174/
