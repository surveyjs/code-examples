# SurveyJS Creator v3 × Nuxt

Get-started demo of SurveyJS Creator v3 inside a [Nuxt](https://nuxt.com/) + Vue SSR app.

Creator mounts in `<ClientOnly>` because it relies on `window`, `localStorage`, and Ace Editor.

## Stack

- Nuxt 3
- Vue 3
- `survey-creator-vue` / `survey-creator-core` / `survey-core` / `survey-vue3-ui` `3.0.0-beta.8`

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000/ (or the URL printed in the terminal).
